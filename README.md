# NovelForge

面向各类长短篇小说创作的文件型 AI Agent 技能框架（OpenClaw Skill）。

NovelForge 把小说创作拆分为一组可追踪、可暂停、可恢复的步骤，涵盖短篇、中篇到长篇连载的全篇幅尺度。帮助作者与 AI 协作管理蓝图、正文、人物关系、事件、伏笔与时间线，减少长篇连载中的设定遗忘、前后矛盾和文风漂移。

## 核心能力

- **故事筑基**：在动笔前对齐题材、基调和目标篇幅，评估故事动力、成长阶梯与阵营复杂度是否足以支撑预期规模。
- **章节化创作**：每章先规划蓝图，再锁定相关上下文，随后进入正文、审查和结算，避免一次性生成整部长篇。
- **文件型记忆**：人物、地点、物品、关系、事件和伏笔以文件形式保存，变更可追踪、可校验。
- **显式依赖**：每章只使用蓝图声明的依赖和允许的一跳关系。
- **双重审查**：正文分别经过文本质量审查和故事连续性/引擎审查；两类审查通过后才能结算事实并交付章节。
- **可替换叙事引擎**：内置 `engines/jin-yong/` 方法卡，也支持从本地资料提炼或安装其他引擎。引擎提供叙事方法，不规定固定文风。

## 工作流程

```text
故事筑基与立项
  → 章节蓝图
  → 上下文锁定
  → 正文起草
  → 文本审查
  → 引擎审查
  → 事实结算
```

每章都有严格的状态顺序：

```text
PLANNED → BLUEPRINT_VALID → CONTEXT_LOCKED → DRAFTED
        → TEXT_PASS → ENGINE_PASS → SETTLED → DELIVERABLE
```

蓝图、正文或其他上游事实发生变化后，相关下游产物会因哈希不匹配而失效，系统会记录审计事件并要求重新经过受影响的步骤。

## 安装与接入

NovelForge 遵循开放智能体技能规范，支持通过 ClawHub 或 Git 一键安装：

### 1. 通过 ClawHub 安装
```bash
clawhub install novelforge
```

### 2. 通过 Git 安装
```bash
git clone https://github.com/Fize/novelforge.git <workspace>/skills/novelforge
```

> **运行依赖**：Python 3.9+ 与 Git。完全由标准库驱动，零额外第三方依赖。

## 自然语言协同创作

安装并激活技能后，直接向 Agent 描述您的创作意图即可：

```text
我想写一篇 1.5 万字的科幻短篇，探讨深空探测器在断联前的最后一次决策，先帮我进行故事筑基与蓝图规划。
```

```text
我想写一本 30 万字的中长篇仙侠小说，主角是普通杂役弟子，请先完成故事立项并评估承载力。
```

```text
规划第一章蓝图：主角排查门派废弃前哨，并为后续章节留下一个可追踪的信物伏笔。
```

```text
继续推进下一章，完成必要的文本质检、引擎审查和事实结算后再交付。
```

流水线具备完全的断点记忆与恢复保障。您可以随时要求暂停或恢复创作，查看当前章节的阻塞原因，或通过本地样本文档两阶段提炼自定义叙事引擎。

## 项目结构

初始化后的小说项目大致如下：

```text
<project>/
├── index.md                      # 故事总索引网络与双向链接图谱
├── outline.md                    # 故事总纲与分卷结构
├── blueprints/<chapter-id>.md    # 章节蓝图（含前置元数据与场景设计）
├── chapters/<chapter-id>.md      # 章节正文
├── characters/                   # 人物档案（含性格底色与压力日志）
├── locations/                    # 地点与场景舞台
├── items/                        # 道具、功法与关键信物
├── factions/                     # 势力、宗门与阵营组织
├── hooks/                        # 伏笔与悬念追踪
├── timeline/                     # 编年史与事实大事件
├── entities/                     # 通用实体设定
└── .novelforge/                  # 唯一的机器系统目录（运行状态与账本）
    ├── state/                    # 项目配置与章节流转状态机
    ├── context/                  # 锁定的 Context Ticket (哈希校验)
    ├── reviews/                  # 文本质检与叙事审查报告
    ├── settlements/              # 事实结算机器流水凭证
    ├── engines/                  # 项目挂载的叙事引擎
    └── audit.jsonl               # 状态流转不可篡改审计流
```
